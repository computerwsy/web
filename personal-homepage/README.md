# Shuyi Wang — Personal Homepage

Responsive bilingual academic homepage. All styles and scripts are inside `index.html`; no build dependencies are needed.

## Preview
Open `index.html` in a browser. Use the 中文 / EN button to switch languages.

## Recommended deployment
Create a public repository named `computerwsy.github.io` and copy `index.html` to its root. In Settings → Pages choose Deploy from a branch, select main and / (root), then Save. GitHub will show the final site URL when deployment succeeds.

Alternatively, merge this branch into `web` and enable Pages for main / (root). The homepage is under the /personal-homepage/ path. Check existing hosting configuration before changing Pages settings.

## Editing
Edit the text in `index.html`. Chinese and English content use the `zh` and `en` classes. Add verified paper links, a portrait, or a public contact address when available. No private contact data or unpublished research details are included.
